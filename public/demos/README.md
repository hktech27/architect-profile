# Demo Videos

Place the following MP4 files in this directory:

| File | Used by |
|------|---------|
| `PreClaimIQ.mp4` | PreClaimIQ — Agentic Insurance Workflow |
| `CoverIQ.mp4` | CoverIQ++ — Policy Intelligence |
| `BR-ImpactLens.mp4` | BR Impact Lens — Rules Intelligence |

Files in `public/` are served at the root by Vite.
With `base: '/architect-profile/'` set in vite.config.js, videos are accessible at:
  /architect-profile/demos/<filename>.mp4
